STM32 & ESP32 嵌入式项目集合
> 本仓库为个人嵌入式实战项目合集，基于STM32 HAL库 + FreeRTOS、ESP32物联网开发，包含四轴无人机飞控系统、无线遥控系统、ESP32三端智能宠物喂食系统（设备+云端+小程序）。覆盖 RTOS多任务调度、串口自定义通信、串级PID闭环控制、卡尔曼滤波、传感器驱动、MQTT物联网通信、微信小程序上位机开发等全套嵌入式核心技术。
📁 整体项目架构
本仓库所有项目完全独立工程，互不耦合：
- P01_Flight_hal：无人机飞控主控端（STM32F103 + FreeRTOS 核心控制）
- P02_Remote_hal：无人机无线遥控端（STM32F103 + ADC采集 + 自定义串口协议，尚硅谷课程标准架构）
- p03_Pet_Feeder：ESP32-S3 智能宠物喂食完整三端系统（设备端+OneNET云+微信小程序）
- 备份工程：PID调参迭代版本、双端通信调试版本，用于学习对比

一、P01_Flight_hal 四轴无人机飞控主控工程
主控：STM32F103C8T6 | 系统：FreeRTOS 实时多任务
飞控端采用高实时性多任务分层架构，根据业务优先级拆分 4 个核心任务，严格划分任务周期与优先级，适配无人机飞行控制实时性要求。
1. FreeRTOS 四大核心任务（优先级 & 周期严格区分）
- power_task（优先级4 / 10s）电源管理最高优先级
  - 采用 任务通知 ulTaskNotifyTake 事件机制，替代队列，节省单片机RAM内存
  - 正常10s超时自动维持电源供电，防止自动关机
  - 收到遥控关机任务通知后，执行设备安全断电、系统停机
  - 跨任务事件同步，解耦通信任务与电源控制逻辑
- flight_task（优先级3 / 6ms）核心飞行控制任务
  - 整个飞控最高实时性任务，固定6ms周期运行
  - 读取 MPU6050 六轴数据，卡尔曼滤波姿态解算，输出欧拉角
  - 执行角度环+角速度环串级PID姿态闭环控制
  - 定高模式下分频采集 VL53L1X 激光测距数据，24ms执行一次高度PID，降低CPU占用
  - PID运算结果转换为四路PWM占空比，驱动无刷电机
- comm_task（优先级2 / 10ms）无线通信解析任务
  - 循环接收遥控端无线串口帧数据
  - 校验帧头帧尾、校验和，过滤错帧、丢包、干扰数据
  - 解析油门、横滚、俯仰、偏航、定高、关机指令
  - 识别关机指令后，通过 xTaskNotifyGive 发送事件给电源任务
  - 实时更新飞行状态机：待机/普通飞行/定高/故障
- led_task（优先级1 / 100ms）状态指示任务
  - 低优先级后台任务，不占用核心算力
  - 双LED标识遥控连接状态，双LED标识飞行模式状态
  - 待机慢闪、飞行快闪、定高常亮、故障熄灭，可视化系统状态
2. 硬件外设驱动
- I2C：MPU6050六轴姿态传感器、VL53L1X激光测距模块
- TIM PWM：四路电机PWM输出，实现电机调速
- UART：无线透传模块数据接收
- GPIO：系统状态LED、电源检测IO
3. 核心算法与业务逻辑
- 卡尔曼滤波融合陀螺仪、加速度计数据，抑制姿态噪声
- 串级PID实现飞行器自稳、姿态修正
- 激光测距实现精准定高闭环控制
- 支持待机、手动飞行、激光定高三模式自动切换
- 遥控断线保护、异常电机锁止、安全关机机制

二、P02_Remote_hal 无人机无线遥控单元（尚硅谷标准架构）
主控：STM32F103C8T6 | 系统：FreeRTOS 实时多任务 | 独立完整工程
遥控端与飞控主控采用双机分离、完全解耦的分布式架构，严格遵循尚硅谷嵌入式开发标准。基于STM32F103C8T6（20KB SRAM小资源单片机）做轻量化RTOS开发，合理分配任务优先级、栈空间与运行周期，实现摇杆采集、按键检测、数据组帧、串口透传、屏幕显示、电源管理全流程模块化任务调度。
1. FreeRTOS 五大核心任务（优先级 & 周期严格区分，适配小内存单片机）
针对STM32F103C8T6硬件资源限制，系统仅分配12KB内存给FreeRTOS操作系统，所有任务统一配置128字节栈空间，按需划分任务优先级与执行周期，杜绝内存溢出、任务卡顿问题。
- power_task（优先级4 / 10s）最高优先级电源管理任务系统最高优先级任务，保障设备电源稳定运行，防止遥控设备自动断电关机
- 采用 vTaskDelayUntil 固定10秒周期执行，精准维持IP5305T电源芯片工作状态
- 周期性调用电源启动函数，持续保活设备供电，避免长时间静置断电
- 独立任务管理电源逻辑，与业务控制任务解耦，提升设备稳定性
comm_task（优先级3 / 10ms）高频通信发送任务核心通信任务，负责遥控数据周期性组帧上报，保障操控实时性
固定10ms执行一次，调用数据发送函数，将摇杆、按键状态打包上传
配合自定义串口通信协议，持续向飞控端透传操控指令，支撑双向通信链路
高频低耗时任务，仅负责数据发送，不做复杂运算，保障通信响应速度
key_task（优先级2 / 20ms）按键检测任务中等优先级业务任务，固定20ms周期扫描物理按键
内置软件消抖逻辑，过滤机械按键抖动干扰，避免误触发
识别模式切换、紧急停机、功能设置等按键事件，更新全局按键状态标志位
事件检测独立封装，不占用通信、采集核心任务算力
joystick_task（优先级2 / 20ms）摇杆ADC采集任务与按键任务同优先级，均衡外设采集算力，固定20ms周期执行
上电完成ADC摇杆硬件初始化，周期性采集四路摇杆模拟量原始数据
对原始ADC数据做软件滑动滤波，消除摇杆物理抖动、电压波动噪声
将采集的原始数值线性映射为标准控制量程，适配飞控端识别逻辑
oled_task（优先级1 / 100ms）最低优先级屏幕显示任务后台低优先级任务，不抢占核心业务任务资源
上电完成OLED屏幕初始化，100ms周期刷新界面数据
实时显示摇杆数值、按键状态、设备连接状态、电源工作状态等信息
人机交互可视化展示，方便调试、校准摇杆参数与设备状态
2. 2.4G通信协议（双向可靠传输）
- 自定义私有串口协议：固定帧头 0xAA、帧尾 0xBB，搭配数据校验和机制
- 数据域封装完整操控数据：四路摇杆俯仰/横滚/油门/偏航数值、按键功能状态、设备模式位、紧急关机标志位
- 飞控端严格校验帧头、帧尾与校验和，自动过滤无线传输过程中的错帧、丢包、电磁干扰数据
- 内置通信状态检测逻辑，支持断线识别、通信异常状态提示，保障远距离操控稳定性
3. 硬件外设与完整业务功能
- ADC外设：四路独立ADC采集，实现双摇杆模拟量高精度采集
- GPIO外设：多路功能按键、设备状态指示灯，实现手动操控与状态提示
- UART外设：对接无线透传模块，实现与飞控端的远距离无线数据交互
- I2C外设：驱动OLED显示屏，实现设备状态可视化人机交互
- 电源模块：IP5305T电源管理芯片，软硬件协同实现设备保活、防断电功能
- 核心业务：支持摇杆精准操控、按键模式切换、紧急停机保护、实时状态显示、稳定无线数据透传，适配无人机全场景操控需求

三、p03_Pet_Feeder ESP32-S3 智能宠物喂食三端系统
整套项目包含：ESP32设备端 + OneNET云端服务 + 微信小程序上位机
全程端云联动，小程序为喂食系统配套上位机，属于本项目完整子模块，非独立项目。
1. 整体通信框架
- 通信协议：MQTT 物联网标准协议
- 设备端 <=> OneNET云平台：长连接双向通信
- 小程序 <=> OneNET云平台：调用开放API实现远程控制
- 设备与小程序不直接通信，云端统一中转，保证稳定可靠
2. ESP32-S3 设备端功能（FreeRTOS多任务）
- 传感器任务：周期采集DHT11温湿度，数据滤波降噪，上传云端
- 舵机与按键任务：本地按键手动投喂、SG90舵机角度控制、本地定时投喂计时
- MQTT网络任务：维持WiFi长连接、断线自动重连、订阅下行指令、上传设备状态数据
3. 硬件外设
- ESP32-S3 WiFi模组
- SG90舵机：执行机械出粮动作
- DHT11温湿度传感器：环境监测
- 物理按键：本地手动投喂
- 状态LED：网络状态、工作状态指示
4. 三端业务流程
- 设备端：本地独立定时投喂、手动投喂、温湿度采集、云端数据上报
- 云端：设备在线托管、数据存储、指令转发、消息队列管理
- 微信小程序：查看实时温湿度、设备在线状态、下发立即投喂指令、配置定时投喂、查看历史投喂记录
5. 容错机制
- WiFi断网后，本地定时任务依旧独立运行，不影响正常喂食
- 网络重连自动恢复云端上报与远程控制功能

🛠 开发环境与技术栈
- 主控芯片：STM32F103C8T6、ESP32-S3
- 开发工具：Keil-MDK5、STM32CubeMX、ESP-IDF、微信开发者工具、串口调试助手
- 实时系统：FreeRTOS（任务、任务通知、信号量、状态机）
- 通信协议：I2C、UART串口自定义协议、MQTT物联网协议
- 核心技术：多任务调度、事件驱动、串级PID、卡尔曼滤波、传感器滤波、端云协同
✨ 核心技术亮点（面试专用）
1. 轻量化RTOS架构：优先使用任务通知替代消息队列，节省F103小内存单片机RAM资源，事件驱动解耦多任务
2. 高实时闭环控制：6ms超高频姿态PID，24ms低频定高PID，分时运算优化CPU负载
3. 可靠串口自定义协议：帧头帧尾+校验和机制，解决无线传输丢包、干扰问题
4. 分层软件设计：驱动层、算法层、业务层完全解耦，代码可移植、可维护
5. 物联网三端联动：ESP32+MQTT+云端+小程序，完整嵌入式物联网应用链路
6. 多重安全保护：遥控断线保护、电机锁止、异常状态识别、离线本地容错运行
