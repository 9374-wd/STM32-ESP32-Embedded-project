# STM32 & ESP32 嵌入式项目集合
> 本仓库为个人嵌入式实践代码仓库，包含四轴无人机飞控、遥控单元、横模小车、CAN‑BootLoader、ESP32智能宠物喂食器多个完整工程，基于STM32 HAL库与FreeRTOS开发，覆盖传感器采集、多任务调度、闭环控制、总线通信、固件升级等嵌入式常见业务场景。

## 📁项目目录
- **P01_Flight_hal**：STM32F103C8T6 四轴无人机飞控主控工程
  - RTOS：基于FreeRTOS实现多任务拆分，独立划分5个业务任务
    1. `sensor_task`：传感器采集任务，高频读取MPU6050陀螺仪加速度计，完成原始数据接收
    2. `comm_task`：遥控通信任务，解析无线遥控帧，识别按键、摇杆数据，检测遥控连接状态、关机指令
    3. `flight_task`：飞行控制任务，执行姿态解算、串级PID运算，20ms周期输出控制量，实现定高模式逻辑
    4. `motor_task`：电机输出任务，将PID输出转换为四路PWM占空比，驱动四个无刷电机
    5. `power_task`：电源管理任务，通过**任务通知**接收关机事件，执行电机停转、系统安全关机流程

  - 算法：卡尔曼滤波对陀螺仪、加速度计做姿态解算；角度环+角速度环**串级PID闭环控制**；激光测距实现高度闭环
  - 硬件外设：
    - I2C：MPU6050六轴姿态传感器、VL53L1X激光测距模块（高度检测）
    - TIM PWM定时器：四路电机驱动输出
    - UART：无线遥控模块串口数据接收
    - GPIO：LED状态指示灯、电源检测IO
  - 业务逻辑：支持IDLE待机、普通手动飞行、激光定高三种工作模式；遥控断线保护；任务通知跨任务事件同步，安全关机流程；异常状态下电机锁止保护。

- **P02_Remote_hal**：无线遥控单元工程
  - 硬件：STM32F103，摇杆ADC采集、按键输入
  - 功能：采集摇杆模拟量与按键，组帧后串口发送给飞控端，实现飞行器远距离操控。

- **完成PID调节‑备份**：飞控调参迭代备份版本，记录PID参数调试过程，便于对比不同参数下飞行器飞行效果。
- **完成双端通讯‑备份**：飞控‑遥控双向通信调试工程，用于调试通信协议、丢包校验、状态交互逻辑。

## 🛠开发环境
- 主控芯片：STM32F103C8T6（飞控/遥控）、ESP32‑S3（宠物喂食器项目）
- 开发工具：Keil‑MDK5，STM32CubeMX图形化配置外设与RTOS，串口调试助手
- 操作系统：FreeRTOS，使用任务、任务通知、信号量，未使用队列做事件通知，减少内存开销
- 通信协议：I2C、UART串口、CAN总线；掌握CAN‑Bootloader固件升级基础流程
- 代码架构：采用HAL库分层驱动，底层硬件驱动与上层业务控制逻辑解耦，便于移植维护。

## ✨核心技术要点
1. **FreeRTOS多任务调度设计**
    根据业务实时性划分不同优先级任务；使用`xTaskNotifyGive`任务通知实现跨任务事件同步，相比队列节省RAM内存；控制任务固定20ms周期执行，保障飞行器闭环控制实时性。

2. **飞行器闭环控制**
    使用卡尔曼滤波融合陀螺仪、加速度计数据，解算飞行器姿态；采用串级PID，外环角度环、内环角速度环完成姿态闭环；结合VL53L1X测距数据实现高度PID定高控制。

3. **传感器工程处理**
    对传感器原始数据做滑动滤波，抑制I2C读取噪声；对传感器故障、数据异常做简单判断，提升系统稳定性。

4. **CAN Bootloader固件升级**
    理解Flash分区划分，区分BootLoader分区与App应用分区；CAN总线接收固件数据包，完成固件烧写跳转基础流程。

5. **系统安全保护机制**
    遥控失联检测、关机事件处理；待机状态电机强制锁止，防止误启动；状态机管理飞行模式，不同模式下选择性开启对应PID运算，减少CPU无效运算。

6. **分层软件思想**
    硬件驱动层、算法层、业务逻辑层分离，驱动接口统一，方便更换硬件外设，提高代码复用性。
