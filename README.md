STM32 & ESP32 嵌入式项目集合
本仓库为个人嵌入式实践代码仓库，包含四轴无人机飞控、遥控单元、横模小车、CAN‑BootLoader、ESP32 智能宠物喂食器多个完整工程，基于 STM32 HAL 库与 FreeRTOS 开发，覆盖传感器采集、多任务调度、闭环控制、总线通信、固件升级等嵌入式常见业务场景。
📁项目目录
P01_Flight_hal：STM32F103C8T6 四轴无人机飞控主控工程
RTOS：基于 FreeRTOS 实现多任务拆分，独立划分 5 个业务任务
sensor_task：传感器采集任务，高频读取 MPU6050 陀螺仪加速度计，完成原始数据接收
comm_task：遥控通信任务，解析无线遥控帧，识别按键、摇杆数据，检测遥控连接状态、关机指令
flight_task：飞行控制任务，执行姿态解算、串级 PID 运算，20ms 周期输出控制量，实现定高模式逻辑
motor_task：电机输出任务，将 PID 输出转换为四路 PWM 占空比，驱动四个无刷电机
power_task：电源管理任务，通过任务通知接收关机事件，执行电机停转、系统安全关机流程
算法：卡尔曼滤波对陀螺仪、加速度计做姿态解算；角度环 + 角速度环串级 PID 闭环控制；激光测距实现高度闭环
硬件外设：
I2C：MPU6050 六轴姿态传感器、VL53L1X 激光测距模块（高度检测）
TIM PWM 定时器：四路电机驱动输出
UART：无线遥控模块串口数据接收
GPIO：LED 状态指示灯、电源检测 IO
业务逻辑：支持 IDLE 待机、普通手动飞行、激光定高三种工作模式；遥控断线保护；任务通知跨任务事件同步，安全关机流程；异常状态下电机锁止保护。
P02_Remote_hal：无线遥控单元工程
硬件：STM32F103，摇杆 ADC 采集、按键输入
功能：采集摇杆模拟量与按键，组帧后串口发送给飞控端，实现飞行器远距离操控。
完成 PID 调节‑备份：飞控调参迭代备份版本，记录 PID 参数调试过程，便于对比不同参数下飞行器飞行效果。
完成双端通讯‑备份：飞控‑遥控双向通信调试工程，用于调试通信协议、丢包校验、状态交互逻辑。
🛠开发环境
主控芯片：STM32F103C8T6（飞控 / 遥控）、ESP32‑S3（宠物喂食器项目）
开发工具：Keil‑MDK5，STM32CubeMX 图形化配置外设与 RTOS，串口调试助手
操作系统：FreeRTOS，使用任务、任务通知、信号量，未使用队列做事件通知，减少内存开销
通信协议：I2C、UART 串口、CAN 总线；掌握 CAN‑Bootloader 固件升级基础流程
代码架构：采用 HAL 库分层驱动，底层硬件驱动与上层业务控制逻辑解耦，便于移植维护。
✨核心技术要点
FreeRTOS 多任务调度设计
根据业务实时性划分不同优先级任务；使用xTaskNotifyGive任务通知实现跨任务事件同步，相比队列节省 RAM 内存；控制任务固定 20ms 周期执行，保障飞行器闭环控制实时性。
飞行器闭环控制
使用卡尔曼滤波融合陀螺仪、加速度计数据，解算飞行器姿态；采用串级 PID，外环角度环、内环角速度环完成姿态闭环；结合 VL53L1X 测距数据实现高度 PID 定高控制。
传感器工程处理
对传感器原始数据做滑动滤波，抑制 I2C 读取噪声；对传感器故障、数据异常做简单判断，提升系统稳定性。
CAN Bootloader 固件升级
理解 Flash 分区划分，区分 BootLoader 分区与 App 应用分区；CAN 总线接收固件数据包，完成固件烧写跳转基础流程。
系统安全保护机制
遥控失联检测、关机事件处理；待机状态电机强制锁止，防止误启动；状态机管理飞行模式，不同模式下选择性开启对应 PID 运算，减少 CPU 无效运算。
分层软件思想
硬件驱动层、算法层、业务逻辑层分离，驱动接口统一，方便更换硬件外设，提高代码复用性。
